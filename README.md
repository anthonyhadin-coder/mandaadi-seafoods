# Mandaadi Seafoods — Storefront & Admin Concept

A responsive fish-only e-commerce storefront inspired by the supplied grocery-store reference layout and adapted for Mandaadi Seafoods.

## Run
Extract the ZIP and open `index.html` in a modern browser. No build step is required.

## Storefront
- Promotional seafood hero and service benefits
- Fish collection tiles
- Fish-only catalogue with search and availability filters
- Available / unavailable labels
- Shopping bag and WhatsApp order enquiry

## Demo admin
- Add fish with a name, price per kg and optional image URL
- Toggle fish availability
- View order enquiries and update status: Pending, Confirmed, Delivered, Cancelled
- Daily revenue counts only orders marked Delivered

## Important limitations
This is a front-end prototype. Demo data is stored in the current browser's localStorage and is not shared between devices or staff. There is no secure login, backend, database, payment gateway, inventory synchronisation or live delivery tracking. Before production, connect a secure backend/database and replace sample fish, prices, images, phone and business policies with Mandaadi-approved details. Product photos are loaded from Unsplash and require internet access.
